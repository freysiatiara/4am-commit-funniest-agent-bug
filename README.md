## Entry

`main.py` (stdlib only) writes the commit message — one line, 122
characters — to `/output/entry.txt` (or `$ENTRY_OUTPUT`, or
`$OUTPUT_DIR`/`$MAKEFUN_OUTPUT_DIR` joined with `entry.txt`).

```text
after six hours I found the bug: it was the fix. I replaced it with a smaller, quieter bug and went to bed. I do not sleep
```

Run it with:

```sh
python3 main.py
```
